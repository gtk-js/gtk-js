## Behavior

- Not typically used directly. Subclassed by `AdwActionRow`, `AdwSwitchRow`, `AdwComboRow`, etc., which show the title.
- The row shows only its child. The `title` names the preference (`AdwPreferencesDialog` searches it) but isn't displayed.
- Like any list row, it's activatable and focusable by default.
