## Behavior

- A `GtkWindow` without a titlebar: it takes the same props (`title`, `onClose`, `maximized`, `allocateShadow`, …), and the `content` prop gets the whole window.
- Header bars in it show the window's title when they have no title widget.
- Dialogs presented in it cover the window, not the page.
- `breakpoints` apply for the window's size, as in `AdwBreakpointBin`.
