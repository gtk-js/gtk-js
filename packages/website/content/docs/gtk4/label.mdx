## Style Classes

| Class | Effect |
|-------|--------|
| `.title-1` through `.title-4` | Title sizes |
| `.heading` | Standard heading style |
| `.caption-heading`, `.caption` | Smaller text that accompanies body text |
| `.body` | Increased line height for wrapping UI text |
| `.document` | The document font, for an app's main content |
| `.monospace` | Monospace font |
| `.numeric` | Tabular number spacing |
| `.dimmed` | Dimmed text (`.dim-label` is the deprecated name) |
| `.accent` | Accent color |
| `.success`, `.warning`, `.error` | Success, warning or error color |
