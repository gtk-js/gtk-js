## CSS Node Tree

```
calendar.view
├── header
│   ├── button
│   ├── stack.month
│   ├── button
│   ├── button
│   ├── label.year
│   ╰── button
╰── grid
    ╰── label[.day-name][.week-number][.day-number][.other-month][.today]
```

Day labels take `:selected` for the selected day, `:checked` for the
`markedDays`, and `:focus` for the keyboard cursor: the arrow keys move it,
Space selects its day, and Ctrl+arrows switch months and years.
