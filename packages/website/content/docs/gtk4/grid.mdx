## Behavior

- Children fill their cells unless their `halign` / `valign` say otherwise.
- Only columns (rows) with a child that expands (`hexpand` / `vexpand`, also when something inside it expands) take extra space, unless the grid is homogeneous.
- Without placement props, children flow naturally.
- Uses CSS Grid for layout.
