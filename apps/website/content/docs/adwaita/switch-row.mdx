## CSS Node Tree

```
row.activatable
  └── box.header
      ├── box.prefixes
      ├── box.title (vertical)
      │   ├── label.title
      │   └── label.subtitle
      └── box.suffixes
          └── switch
```

## Behavior

- Activating the row (a click, or Enter or Space while it has the focus) toggles the switch,
  then calls `onActivated`. Clicks and drags on the switch itself are the switch's own.
- The switch can't take the focus; the row is a single Tab stop.
- `prefixWidget`, `suffixWidget` (after the switch), `titleLines`, `subtitleLines` and
  `tooltipText` work as on `AdwActionRow`.
