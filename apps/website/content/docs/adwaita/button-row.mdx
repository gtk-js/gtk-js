## Style Classes

| Class | Effect |
|-------|--------|
| `.suggested-action` | Uses the accent color for the background, for an important action. Use it sparingly |
| `.destructive-action` | Uses destructive colors, to warn of an action's consequences |

Button rows are usually the last rows of an `AdwPreferencesGroup`. With `separateRows`, the group shows each row as a card of its own instead.
