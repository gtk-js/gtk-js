## Behavior

- Like CSS container queries, but evaluates the bin's own width/height.
- Last matching breakpoint wins.
- Conditions use libadwaita's syntax: `min-width`, `max-width`, `min-height`, `max-height` in `px`, `pt` or `sp`, `min-aspect-ratio` and `max-aspect-ratio`, combined with `and`, `or` and parentheses. Invalid conditions log an error and never apply.
- The child fills the bin.
- Fires `onApply`/`onUnapply` callbacks when breakpoints activate/deactivate.
